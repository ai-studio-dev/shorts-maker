# 유림거사 서재 (메타버스 라운지) — 1단계 프로토타입

달밤 골목 → 마당 → 한옥 서재로 걸어 들어가, NPC에게 말을 걸면 기존 서비스가 열리는 3D 공간입니다.

| 위치 | NPC/오브젝트 | 연결 |
|---|---|---|
| 대문 앞 | 안내 동자 | 사주·타로 자리로 길안내 |
| 서재 왼쪽 | 유림거사 | `saju-widget.vercel.app` (라운지 안 iframe) |
| 서재 오른쪽 | 타로 선생 | 무료 1장 `/free` (iframe) · 3장/5장 결제 페이지 (새 창) |
| 뒷벽 족자 | 오늘의 일진 | 오늘 일진 + 내 일간과의 관계 풀이 (무료) |
| 유림거사 뒤 진열장 | 분야별 소품 6개 | 재물·건강·직업사업·애정가족·궁합·반려동물 → 사주 위젯 |

- 입장 시 생년월일을 넣으면 **일주**를 계산해 아바타 도포 색을 일간 오행색으로 입힙니다.
- 이름·생년월일은 그 브라우저의 `localStorage`에만 저장됩니다(서버 전송 없음).
- PC: 바닥 클릭 / WASD·방향키, 모바일: 바닥 탭. 말풍선을 누르면 그 NPC 앞으로 걸어가 대화합니다.
- 서버·빌드 도구가 필요 없는 정적 사이트입니다. Three.js(r169, MIT)는 `vendor/`에 포함돼 있습니다.

## 로컬 실행

```bash
cd lounge
python3 -m http.server 8765   # → http://localhost:8765
```

(ES 모듈이라 `index.html`을 파일로 직접 열면 동작하지 않습니다. `?debug`를 붙이면 콘솔에서 `__lounge`로 상태를 볼 수 있습니다.)

## 배포 방법 (택1)

1. **별도 Vercel 프로젝트** — 이 저장소를 Vercel에 연결하고 *Root Directory* 를 `lounge` 로 지정. Framework: Other, 빌드 명령 없음.
   이후 `lounge.yurimfortune.com` 같은 서브도메인을 붙이면 됩니다.
2. **랜딩(yurimfortune.com)에 포함** — `lounge/` 폴더 통째로 Next.js 프로젝트의 `public/lounge/` 에 복사 → `https://yurimfortune.com/lounge/` 로 접속.

랜딩 페이지에는 "서재에 걸어 들어가기" 같은 버튼 하나만 추가하면 됩니다.

## 분야별 소품(진열장)

| 소품 | 분야 | 지금 연결 |
|---|---|---|
| 💰 금두꺼비 | 재물운 | 사주 위젯 첫 화면 + "「재물운」 메뉴를 눌러주세요" 안내 |
| 🌿 약초 항아리 | 건강운 | 〃 |
| 📜 주판과 장부 | 직업·사업운 | 〃 |
| 💞 원앙 한 쌍 | 애정·가족운 | 〃 |
| 🤝 붉은 실 매듭 | 궁합 | 〃 (「궁합 보기」) |
| 🐾 강아지 방석 | 반려동물 | 〃 (「반려동물 코너 보기」) |

사주 위젯에는 분야별 바로가기 주소가 없어서, 지금은 첫 화면을 열고 상단에 어떤 메뉴를 누르면 되는지 안내만 띄웁니다
(**사주 위젯 코드는 건드리지 않습니다**). 나중에 사주 위젯 쪽에서 `?report=wealth` 같은 주소를 지원하게 되면
`js/config.js` 의 `SAJU_TOPICS[].url` 만 바꾸면 바로 그 화면으로 연결됩니다.

## 주소 바꾸기

서비스 주소는 `js/config.js` 한 곳에 모여 있습니다. 랜딩이 쓰는 `tarot.yurimfortune.com` 으로 통일하려면 여기만 바꾸세요
(바꾼 도메인도 iframe 차단 헤더 — `X-Frame-Options`, CSP `frame-ancestors` — 가 없어야 라운지 안에서 열립니다).

## 파일 구성

```
lounge/
├─ index.html        HUD · 입장 폼 · 대화창 · 일진 카드 · 서비스 창
├─ css/style.css
├─ js/
│  ├─ main.js        렌더 루프, 이동/카메라, 말풍선, 대화, iframe 열기
│  ├─ world.js       골목·마당·한옥 서재, NPC 배치, 걸을 수 있는 영역/장애물
│  ├─ avatar.js      저폴리 인물(도포·갓·두건) + 걷기 애니메이션
│  ├─ saju.js        60갑자 일주/일진 계산, 오행 관계 문구
│  └─ config.js      사주·타로·홈 링크
└─ vendor/three.module.min.js
```

## 알려진 한계 / 다음 단계

- 일주 계산은 날짜 기준 간단 버전(자시 23시 경계·음력 미지원). 정식 풀이는 사주 위젯이 담당합니다.
- 사주 위젯 안의 토스 결제가 iframe에서 막히는 브라우저가 있으면 상단 **새 창으로 열기** 버튼을 쓰면 됩니다.
- 2단계 후보: 무료운세 도장 모으기, 방문자 수/다른 방문자 아바타(실시간 서버 필요), 공유용 OG 이미지, 배경 음악.
